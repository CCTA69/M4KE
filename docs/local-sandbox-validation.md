# DGX-only 启动与行驶仿真：验证记录

日期：2026-10-10。范围：本次独立 PR 的源码、Windows 本机浏览器和测试夹具；不是 DGX 硬件测评或实物验收。

## 已完成

- 新增本地模型任务评测、离线启动、行驶数值/碰撞及生产 CSP 回归；另增加轮组半径/圈数关系、轮轴保持、几何不变、离地无牵引与撞停不空转测试。
- Vue/TypeScript 类型检查和生产构建通过；物理引擎按需加载且随构建本地打包，不使用 CDN。
- 原有工作台浏览器回归 18 项通过：五阶段、草稿停留、选择上下文冻结、候选确认/过期拒绝、显隐独立保存、错误状态与中英文等。
- 电气浏览器回归 16 项、独立视口回归 14 项通过；源码归档与离线恢复契约测试 11 项通过。
- 行驶浏览器夹具通过响声前进、安静停止、复位、非法参数阻断、输入框快捷键隔离、窄屏、无外部请求及无设计写入检查。
- 修复实页发现的 WASM 初始化失败：生产 CSP 仅增加 `wasm-unsafe-eval`，不开放 JavaScript `unsafe-eval` 或远程脚本；浏览器测试复用生产 CSP。
- 修复高 DPI 视口尺寸，增加 2× 像素密度回归；可指定模型车头 +X/−X，不修改源几何。
- 轮胎与轮圈同轴滚动，角度绑定真实位移，不使用固定时长动画；已增加不同轮径转速比例和复位清零的浏览器断言。
- 本地制作包的整车 38 个 STL、188,858 个三角面重新计算外廓为 **286 × 182 × 76 mm**。这是已组装模型的包围盒，不是单块打印板尺寸、实物量测或尺寸公差报告。本 PR 不修改这些私人制作包文件。

## 完整套件的环境限制

本机最终源码回归：520 项，其中 495 通过、22 按既有资产条件跳过、3 环境失败。新增 17 项回归通过。现有 `printer-tls.test.mjs` 的 3 项测试因找不到 `openssl` 可执行程序而失败。没有放宽 TLS 检查，也没有把环境失败记作通过；Linux CI 可继续运行这三项测试。

部分原有测试需要未随公开源码再分发的 CAD/资产，因此按现有条件跳过。公开源码检查与有资产的原生 CAD 验证是两个不同验收层次。

GitHub Ubuntu CI 已通过源码回归、类型/构建和源码归档测试，包括本机缺失 OpenSSL 的 TLS 用例。第一轮 CI 暴露新浏览器夹具直接引用 Vite 缓存文件造成的冷启动竞争；已改为 Vite 解析的虚拟模块并隔离缓存，不放宽 CSP 或删除断言。以 PR 最新 CI 结果为最终跨平台状态。

浏览器测试均使用本地测试数据和响应夹具，未调用真实 Qwen、在线模型、供应商或实体打印机。

## 可复现命令

```bash
npm ci
npm run check:syntax
npm run typecheck
npm run build
npm run test:source
# Linux 首次准备：npx playwright install --with-deps chromium
npm run test:e2e
python -B tests/submission_package_test.py
```

Windows 可以设置 `M4KE_BROWSER_EXECUTABLE` 指向已安装的 Edge/Chrome。TLS 测试需要 OpenSSL，可通过 `OPENSSL_EXE` 指定已安装程序；不要跳过证书校验来让测试变绿。

## 尚未证明

- 旧信任记录属于专用 SSH 服务，不能直接用于验证新的直连 SSH 服务；直连身份尚未确认。没有发送凭据、改信任记录、安装模型或重启远端服务。
- 尚无本轮 122B/MiniMax 的真实吞吐、显存/统一内存峰值或应用成功率，不能用估算代替结果。
- `dgx-preflight.py` 是只读库存检查，不证明模型能生成合格 CAD。三个合约案例是小样本筛选，不是完整模型排名。
- 尚未断开网络、关闭开发电脑，在 DGX 上重新启动并完成“新需求 → 选件问答 → 修改 → 确认 → 原生 CAD/电气检查 → 导出”的完整验收。
- 包围盒行驶预演不模拟真实悬挂、轮胎、固件、声学噪声、供电动态或热学，不输出工程 PASS，不等同实物测试。
